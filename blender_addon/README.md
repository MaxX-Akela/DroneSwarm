# DroneSwarm Blender add-on

Install: zip the `droneswarm` folder and add it in Blender via Edit > Preferences > Add-ons > Install.

- **File > Export > Swarm animation (.csv)** exports one csv per drone object.
- **ArUco maps** (3D View > Sidebar > DroneSwarm, or File > Import/Export > ArUco map):
  - import a Clover map `.txt` (`id size x y z z_angle y_angle x_angle`, angles in radians);
  - generate a grid map or add single markers;
  - export the markers back to a `.txt` for `aruco_map`.

  Marker textures, materials and the map backplate are generated by the add-on
  (ArUco ORIGINAL 5x5 dictionary, ids 0..1023, which is Clover's default). Units are meters.

Tests for the Blender-independent parts: `python3 -I blender_addon/tests/test_aruco.py`.
