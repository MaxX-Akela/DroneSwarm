# DroneSwarm

Software for creating drone shows on the
[COEX Klever 4.2](https://klever-doc.tech/ROS1/ru/) and [Technic 6S](https://docs.skyris.ru/technic6S/) platforms.

## Images for OrangePi 5 Pro / Raspberry Pi 4

> 🚧 The image for **Technic 6S** and **OrangePi 5 Pro** is still in development. Only the Clover image for Raspberry Pi 4 is ready for now.

A pre-configured image with the software installed and set up is available in the [Releases](https://github.com/MaxX-Akela/DroneSwarm/releases) section.

## Manual Package Build

If you cannot install the ready-made system image, you can install the show software via [apt](https://github.com/MaxX-Akela/DroneSwarm/blob/main/docs/ru/apt.md) or build it from source using these [instructions](https://github.com/MaxX-Akela/DroneSwarm/blob/main/docs/hand_installation.md).

> Building from source may lead to package version incompatibilities
> and a non-functional image. If you are unsure, use the ready-made image.
