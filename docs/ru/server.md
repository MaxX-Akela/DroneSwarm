# Работа с сервером

Сервер — это окно на компьютере оператора. Оно показывает состояние всех дронов в таблице и отправляет им команды. Сервер написан на Python с PyQt5 и работает на Windows и Ubuntu.

## Запуск

Установите зависимости и запустите `core.py`:

```bash
pip install PyQt5
python3 server/core.py
```

При запуске сервер открывает три порта:

| Порт | Протокол | Для чего |
|---|---|---|
| 9000 | UDP | дроны ищут сервер |
| 9010 | TCP | команды серверу → дронам |
| 9001 | UDP | телеметрия дронов → серверу |

Эти порты должны быть открыты в брандмауэре компьютера. Если порт занят, в консоли сервера появится `ERROR: can't bind ...`. Порты и другие настройки меняются в [конфигурации сервера](extras/config.md).

> Компьютер и дроны должны быть в одной сети. Дроны находят сервер по широковещательному запросу, поэтому IP-адрес сервера нигде вводить не нужно.

## Синхронизация времени

Чтобы дроны стартовали одновременно, часы на них должны совпадать с часами сервера. Для этого на компьютере с сервером нужно запустить `chrony` с конфигом `server/chrony/chrony-server.conf` (он же лежит в `examples/chrony/server.conf`):

```
local stratum 10
allow
```

Этот конфиг объявляет сервер источником времени без выхода в интернет и разрешает подключаться любым клиентам. Дроны сами добавят сервер в свой `chrony` после того, как найдут его.

## Таблица дронов

Дрон появляется в таблице, как только пришла его телеметрия. Каждая ячейка окрашена по состоянию: зелёная — всё хорошо, жёлтая — предупреждение, красная — ошибка. Цвет ячейки с именем — худшее состояние в строке. Если телеметрии нет больше 5 секунд (`drone_timeout`) или пропала TCP-связь, вся строка становится красной, а в колонке `mode` пишется `OFFLINE`.

| Колонка | Что показывает |
|---|---|
| copter ID | имя дрона (`hostname`). Галочкой отмечаются дроны, которым пойдёт команда |
| version | версия клиента. Жёлтая, если не совпадает с версией сервера или в коде есть правки |
| animation ID | название загруженной анимации. Красная, если файла нет или он не разобран |
| battery | напряжение батареи |
| system | есть ли связь с полётным контроллером |
| sensors | свежесть позиции от камеры; жёлтая, если не отвечает дальномер |
| mode | режим полёта и признак `armed` |
| checks | результат проверки перед полётом: `OK`, `WARN (n)` или `FAIL (n)`. Подробности — в подсказке при наведении |
| current x y z yaw frame_id | положение дрона в `aruco_map` |
| start x y z | первая точка анимации |
| dt | расхождение часов дрона и сервера в секундах и источник (`chrony` или `ntp`) |

Колонка `start` сравнивает текущее положение с первой точкой анимации по плоскости XY: до 0.3 м — зелёная, до 1 м — жёлтая, дальше — красная. Так видно, что дрон стоит не на своём месте. Когда дрон взлетел, колонка не окрашивается.

Двойной щелчок по ячейке открывает окно с активным конфигом дрона и последними 30 ошибками и предупреждениями.

## Панель управления

Большинство кнопок работает с отмеченными галочкой дронами.

| Кнопка | Что делает |
|---|---|
| **Проверка (Preflight check)** | запускает проверку на выбранных дронах немедленно |
| **Start animation** | запускает анимацию на выбранных дронах через время из поля **Start after** |
| **Pause** | дрон зависает в текущей точке |
| **Посадка (Land selected)** | посадка выбранных дронов |
| **Land ALL** | посадка всех дронов в таблице |
| **Emergency land** | то же, но с подтверждением, для всех сразу |
| **Взлет (Takeoff)** | взлёт на высоту из поля **Z** (спрашивает подтверждение) |
| **Disarm selected / Disarm ALL** | остановка моторов (спрашивает подтверждение) |
| **Test leds** | проверка ленты |
| **Reboot FCU** | перезагрузка полётного контроллера |
| **Calibrate gyro / level** | калибровка гироскопа и уровня |

Кнопки **Визуальная посадка** и **Flip**, а также поле **Play music** пока ничего не делают, это заготовки.

> **Disarm** в полёте приведёт к падению дрона. Используйте его только на земле или в самой крайней ситуации.

### Запуск анимации

1. Отметьте галочками дроны.
2. Нажмите **Проверка** и убедитесь, что колонки `checks`, `start` и `dt` зелёные.
3. Задайте в **Start after** время до старта (в секундах), чтобы успеть отойти.
4. Нажмите **Start animation**.

Если у дрона проверка не пройдена, он откажется играть анимацию и напишет `REFUSED play` в консоль. Для тестов на стенде включите **Developer mode (ignore self-check)**.

## Меню

### Selected drones

Всё, что в этом меню, применяется к отмеченным дронам.

**Send** — отправка файлов на дроны:

| Пункт | Что отправляет |
|---|---|
| Animations... | папку с анимациями: для каждого дрона берётся файл, в имени которого есть его имя (`clover-1.csv` для `clover-1`) |
| Animation... | один файл анимации всем выбранным дронам |
| Camera calibrations... | папку с калибровками камеры (`.yaml`), файл выбирается так же, по имени дрона |
| Aruco map... | карту маркеров `map.txt`; после загрузки перезапускается Clover |
| Configuration... | файл `.ini` с настройками дрона. **Modify** обновляет только указанные ключи, **Rewrite** заменяет конфиг целиком |
| Launch files folder... | все `.launch` и `.yaml` из папки |
| FCU parameters file... | файл параметров PX4 (`.params`), сразу загружается в полётный контроллер |
| File... | любой файл, путь на дроне спросит окно |
| Command... | любую shell-команду; результат придёт в консоль |

Место, куда на дроне кладутся калибровка, карта и launch-файлы, задаётся в разделе `[paths]` [конфигурации сервера](extras/config.md).

Остальные пункты:

* **Restart service** — перезапуск `chrony`, `ros` (Clover) или `swarm` (клиент DroneSwarm);
* **Update (git pull + restart)** — обновление клиента и его перезапуск;
* **Reload animation** — заново прочитать файл анимации;
* **Reboot** — перезагрузка компаньон-компьютера (30–60 секунд).

> Загрузка анимации, перезапуск сервисов, перезагрузка и обновление **не выполняются**, пока дрон в воздухе (`armed`). Исключение — перезапуск `chrony`.

### Server

* **Edit server config** — правка `server/config/server.ini`;
* **Edit any config** — правка любого `.ini`-файла;
* **Update server git** — `git fetch` и `git pull --rebase` в папке сервера;
* **Restart server** — перезапуск сервера.

### Table

**Select all** и **Deselect all** — отметить или снять галочки у всех дронов.

## Консоль

В нижней части окна — консоль сервера. Туда попадают подключения и отключения дронов, ответы на команды (`file written`, `config updated`, результат `run_command` и т.д.) и ошибки. Сообщения дронов подписаны их именем в квадратных скобках.

> Канал команд не защищён паролем: любой, кто в сети, может отправить дрону команду. Запускайте шоу только в отдельной сети, как рекомендовано в [быстром старте](fast_start.md).
