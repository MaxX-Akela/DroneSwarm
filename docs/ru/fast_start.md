# Быстрый старт

## Необходимое оборудование

* Комплект дронов на прошивке [PX4](https://px4.io) с образами [Clover](https://github.com/CopterExpress/clover) или [Technic](https://docs.skyris.ru/technic6S/)
* Компьютер с Windows или Ubuntu либо [симулятор Clover](https://klever-doc.tech/ROS1/ru/simulation.html)
> Рекомендуем Ubuntu или симулятор: там всё работает без проблем.
* Wi-Fi-роутер с поддержкой 2.4 и 5 ГГц
> Главное, чтобы ваши устройства поддерживали 5 ГГц.

## Подготовка оборудования и ПО

Пакет DroneSwarm состоит из двух частей: [сервера]() и [дрона (клиента)](). Подробнее остановимся на части дрона. Запустить её можно тремя способами:

1. **Готовый образ.** Самый простой вариант: скачайте последний релиз для вашей платы-компаньона.

   > 🚧 Образ для Technic 6S и Orange Pi 5 Pro пока в разработке. Для них используйте способ 2 или 3 (возможны недоработки).

2. **Установка через apt.** Чуть сложнее, подробности в [этом гайде](/ru/extras/apt.md).
3. **Сборка из исходников.** Инструкции для каждой платформы: [Clover](/ru/extras/clover_installation.md), [Technic](/ru/extras/technic_installation.md).

> Обычным пользователям рекомендуем способ 1. Если образ из релизов не запускается, используйте способ 2.

Скачайте образ из раздела Releases на GitHub и установите [balenaEtcher](https://etcher.balena.io). Исходный код сервера скачайте на компьютер через `git clone` или ZIP-архивом и распакуйте.

## Запуск клиента

1. Запишите скачанный образ на карту MicroSD через Etcher.
2. Вставьте карту в Raspberry Pi 4 или Orange Pi 5 Pro на дроне, включите дрон и дождитесь появления сети `clever-xxxx` или `technic-xxxx`.

   > При питании дрона от аккумулятора вне полётной зоны снимите пропеллеры или используйте другой источник питания.

   > Raspberry Pi 4 и Orange Pi 5 Pro чувствительны к питанию. Через USB-C используйте мощный блок питания.

3. Подключитесь к сети дрона, используя пароль от образа: [Clover](https://klever-doc.tech/ROS1/ru/wifi.html), [Technic](https://docs.skyris.ru/technic6S/ConnectingToWi-Fi.html).
4. Подключитесь к микрокомпьютеру по SSH. Данные для подключения у разных марок дронов разные: [Clover](https://klever-doc.tech/ROS1/ru/ssh.html), [Technic](https://docs.skyris.ru/technic6S/SSH.html).
5. Выполните скрипт, который подключит дрон к вашему роутеру и изменит `hostname`:

   > `hostname` это имя дрона в таблице на сервере.

```bash
   drone-setup <WIFI-SSID> <WIFI_PASS> <NAME>
```

   Пример:
```bash
   drone-setup Keenetic-8989 iloverclover4 clover-1
```
   (для Technic используйте имя вида `technic-1`)

Теперь дроны должны подключиться к вашему роутеру. Если этого не произошло, смотрите [Решение проблем и FAQ](troubleshooting.md).
