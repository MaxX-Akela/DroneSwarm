# Описание модуля анимации

Модуль `drone/modules/animation.py` читает файл анимации, подготавливает кадры под конкретного дрона и выполняет их. Файл анимации лежит на дроне как `drone/animation.csv` и обычно приходит с сервера: **Selected drones → Send → Animation...** Сами файлы создаются в Blender: [Создание анимации](../blender_addon.md).

## Формат файла

```
my_show
1,0.0,0.0,0.0,0.0,255,0,0
2,0.0,0.0,0.0,0.0,255,0,0
3,0.0,0.0,0.1,0.0,255,0,0
...
```

* **Первая строка** из одного значения — название анимации (`animation ID` на сервере). Если её нет, название будет `No animation id`, и ячейка на сервере станет жёлтой.
* **Строка кадра** — восемь полей: `номер, x, y, z, yaw, red, green, blue`. Координаты в метрах, угол в радианах, цвет 0–255.
* **Строка из двух значений** меняет задержку между следующими кадрами. Вторым значением идёт время в секундах.

Если файл пустой, не открывается, либо в нём нет кадров или есть нечитаемая строка, анимация получает состояние-ошибку (оно видно в подсказке колонки `animation ID`), и запустить её нельзя.

Если параметр `yaw` в [конфиге](config.md) не равен `animation`, то вместо угла из файла используется заданный угол в градусах.

## Из чего состоит анимация

Модуль делит кадры на пять участков. Деление идёт по тому, как движется дрон (порог движения — 1 см между кадрами):

| Участок | Что в нём |
|---|---|
| статика в начале | дрон стоит на месте |
| взлёт | дрон движется вверх, не смещаясь в плоскости |
| маршрут | основная часть шоу |
| посадка | снижение в конце, без смещения в плоскости |
| статика в конце | дрон снова стоит на месте |

Какие участки играть, определяют параметры `output_*` в конфиге. По умолчанию играются взлёт, маршрут и посадка, а статика в начале и в конце пропускается.

## Подготовка кадров

При загрузке файла и при каждом изменении конфига кадры проходят по цепочке:

1. **`transform`** — масштаб и сдвиг: `x' = ratio · x + common_offset + private_offset`.
2. **`mark_stand_frames`** — участки статики помечаются как `stand` (если высота ниже `takeoff_level`) или `fly`.
3. **`apply_flags`** — выбираются участки по `output_*`. Одновременно строится второй список кадров — для старта «со взлёта».
4. **`mark_flight`** — вставляются служебные кадры:
   * `arm` — перед первым полётным кадром, на время `arming_time`, запускает моторы;
   * `takeoff` и `reach` — во втором списке: взлёт на `takeoff_height` и затем подлёт к первой точке (даётся `takeoff_time` и `reach_first_point_time`);
   * `land` — перед последним полётным кадром, с задержкой `land_delay`.

## Как стартует анимация

У модуля два варианта старта:

* **`takeoff`** — дрон стоит на земле, сам взлетает на `takeoff_height` и затем летит к первой точке анимации;
* **`fly`** — анимация сразу начинается с первой точки; так стартуют, если взлёт уже есть в самой анимации.

Параметр `start_action` задаёт выбор. В режиме `auto` выбирается `takeoff`, если первая точка выше `takeoff_level`, иначе `fly`.

Если включён `check_ground`, перед стартом проверяется, что самая нижняя точка анимации не уходит под землю. Высота земли — это текущая высота дрона (`ground_level = current`) или заданное число. Если разница больше 0.2 м, клиент пишет ошибку вида `animation is lower than ground level for 0.35m` и не стартует.

## Выполнение кадров

Для каждого кадра `execute_frame()` делает:

| Действие кадра | Что происходит |
|---|---|
| `arm` | отправляет точку с автозапуском моторов |
| `fly`, `reach` | отправляет точку `x, y, z, yaw` в системе `aruco_map` и не ждёт прилёта |
| `takeoff` | красная лента, взлёт, после зелёное мигание |
| `land` | посадка, красное мигание, ожидание остановки моторов, потом лента гаснет |

Для кадров `arm`, `fly` и `reach` дополнительно устанавливается цвет ленты из кадра. Время между кадрами берётся из поля задержки: каждый кадр выполняется в момент `старт + сумма задержек предыдущих`, а не «через 0.1 секунды после предыдущего». Поэтому плавность движения не зависит от того, сколько времени заняла отправка команды.

Если пришла команда `land`, `stop` или другая, воспроизведение прерывается сразу.
