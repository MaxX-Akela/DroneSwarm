# Создание анимации

Анимацию шоу делают в [Blender](https://www.blender.org). Для этого есть аддон DroneSwarm. Он умеет две вещи:

* экспортировать движение объектов-дронов в файлы `.csv`, которые понимает клиент;
* собирать, импортировать и экспортировать карту ArUco-маркеров для Clover.

## Установка аддона

1. Возьмите файл `droneswarm.zip` из папки `blender_addon` (или заархивируйте папку `droneswarm` сами — внутри архива она должна лежать в корне).
2. В Blender откройте **Edit → Preferences → Add-ons → Install**, выберите архив и включите аддон **DroneSwarm**.

Аддон рассчитан на Blender 2.80 и новее.

## Анимация дронов

### Подготовка сцены

1. Каждый дрон — это отдельный объект (например, куб или пустышка). Имя объекта станет именем файла и должно совпадать с `hostname` дрона. Например, объект `clover-1` → файл `clover-1.csv`.
2. Двигайте объекты и расставляйте ключевые кадры как обычно. Единицы Blender — метры. Начало координат сцены совпадает с началом координат карты ArUco.
3. Чтобы задать цвет ленты, добавьте объекту материал и назовите его слот так, чтобы в названии было `led_color`. Цвет берётся из узла `Emission`, `Diffuse` или `Principled BSDF`. Цвет можно анимировать, как и положение. Без такого материала лента будет чёрной.
4. Границы анимации задаются обычными **Start** и **End** на временной шкале.

> Клиент проигрывает кадры с шагом 0.1 секунды (10 кадров в секунду). Поставьте в Blender частоту 10 fps, иначе движение пройдёт быстрее или медленнее, чем задумано.

### Экспорт

**File → Export → Swarm animation (.csv)**, выберите папку. Для каждого дрона создаётся файл `<имя объекта>.csv`.

Параметры экспорта:

| Параметр | Что значит |
|---|---|
| Use name filter for objects | экспортировать только объекты, в имени которых есть заданная подстрока. Иначе экспортируются **все видимые** объекты сцены |
| Name identifier | эта подстрока (по умолчанию `clever`) |
| Speed limit | предупреждать, если скорость выше (по умолчанию 3 м/с) |
| Distance limit | предупреждать, если дроны ближе друг к другу (по умолчанию 1.5 м) |
| Show detailed animation warnings | выводить предупреждение для каждого кадра, а не только итоговое |

Скорость и расстояния проверяются только как предупреждения: файл всё равно создаётся. Посмотрите их в консоли Blender (**Window → Toggle System Console**) или в строке состояния.

> Если у вас в сцене есть камера, свет или карта маркеров, включите фильтр по имени, иначе для них тоже создадутся файлы.

### Что внутри файла

Первая строка — название анимации (имя `.blend`-файла). Оно показывается на сервере в колонке `animation ID`. Дальше по строке на каждый кадр:

```
номер_кадра,x,y,z,yaw,red,green,blue
```

Координаты в метрах, `yaw` в радианах, цвет от 0 до 255. Подробнее о том, как клиент читает файл: [Описание модуля анимации](extras/animation.md).

## Карта ArUco

Дрон определяет своё положение по картe маркеров на полу. Файл карты — обычный текст формата Clover `map.txt`. Аддон позволяет нарисовать её в той же сцене, где вы делаете анимацию, чтобы сразу видеть, где стоят маркеры относительно дронов.

Панель находится в **3D View → Sidebar (клавиша N) → DroneSwarm**. Те же команды есть в **File → Import / Export → ArUco map (.txt)**.

| Кнопка | Что делает |
|---|---|
| Import map | загрузить `map.txt`. Можно заменить текущую карту и создать подложку |
| Export map | сохранить маркеры сцены в `map.txt` (опционально только выбранные) |
| Generate grid | создать сетку маркеров |
| Add marker | добавить один маркер в позицию 3D-курсора |
| Update backplate | пересоздать белую подложку под маркерами |

### Генерация сетки

Параметры:

* размер маркера (по умолчанию 0.33 м);
* количество маркеров по X и по Y (2 × 4);
* расстояние между центрами по X и Y (1 м);
* номер первого маркера;
* «Start at bottom left» — нумеровать с левого нижнего угла (по умолчанию с левого верхнего);
* «Replace current map» — удалить прежние маркеры;
* «Create backplate» и отступ подложки.

Номера идут по строкам вдоль оси X. Центр первого столбца и нижней строки находится в точке `(0, 0)`.

### Формат map.txt

```
# id    length  x    y    z    rot_z  rot_y  rot_x
0       0.33    0    3    0    0      0      0
```

Каждая строка — один маркер: номер, размер стороны, положение центра, углы поворота в радианах. Пустые строки и комментарии после `#` пропускаются. В строке могут быть только первые два числа (`id size`): остальные станут нулями.

Аддон использует словарь ArUco **ORIGINAL 5×5**, номера от 0 до 1023 — это словарь Clover по умолчанию. Картинки маркеров и материалы создаются сами. Все маркеры лежат в коллекции `ArUco map`, а подложка называется `aruco_backplate`.

### Как отправить карту на дроны

Экспортируйте `map.txt` и отправьте его с сервера: **Selected drones → Send → Aruco map...** После загрузки на дронах перезапустится Clover.

## Типичный порядок работы

1. Сгенерируйте или импортируйте карту маркеров.
2. Расставьте объекты-дроны и сделайте анимацию.
3. Экспортируйте анимацию, проверьте предупреждения о скорости и расстоянии.
4. Экспортируйте карту маркеров.
5. Отправьте карту и анимации на дроны через сервер: [Работа с сервером](server.md).
