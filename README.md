# DroneSwarm

## [English version](https://github.com/MaxX-Akela/DroneSwarm/blob/main/README_EN.md)

Программное обеспечение для создания шоу дронов на платформах
[COEX Klever 4.2](https://klever-doc.tech/ROS1/ru/) и [Technic 6S](https://docs.skyris.ru/technic6S/).

## Образы для OrangePi 5 Pro / Raspberry Pi 4

Предварительно готовый образ с установленным и настроенным программным обеспечением доступен в разделе [Releases](https://github.com/MaxX-Akela/DroneSwarm/releases).

## Ручная сборка пакетов

Если у вас нет возможности установить готовый образ системы, то вы можете установить ПО для шоу через [apt](https://github.com/MaxX-Akela/DroneSwarm/blob/main/docs/ru/apt.md) или собрать из исходников по этой [инструкции](https://github.com/MaxX-Akela/DroneSwarm/blob/main/docs/hand_installation.md).

> Сборка из исходников может привести к несовместимости версий пакетов
> и неработающему образу. Если вы не уверены, используйте готовый образ.
